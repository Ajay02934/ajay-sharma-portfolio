# Ajay Sharma — Developer Portfolio

Professional portfolio for **Ajay Sharma**, focused on Laravel/PHP, WordPress, React and AI automation.

## Stack
- PHP, Laravel, CodeIgniter, MySQL
- WordPress, Multisite, ACF
- React, JavaScript, jQuery, AJAX
- REST APIs, Node.js, Socket.io
- n8n, LLM workflows, AI agents
- Docker, Nginx, AWS, Cloudflare, Git

## Local preview
Open `index.html` directly in a browser, or serve the folder with any static web server.

## GitHub Pages
The repository is structured as a static site and includes a GitHub Actions workflow for Pages deployment. If Pages is not automatically enabled for the repository, open **Settings → Pages**, select **GitHub Actions** as the source, then run/push to `main`.

## Customize
Update the placeholder email and LinkedIn URL in `index.html` before sharing the portfolio publicly.
